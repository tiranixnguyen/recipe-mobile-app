# AvailabilityBadge

Cho biết món có nấu được ngay với đồ trong Tủ đồ hay không.

- Không thiếu gì: chữ "Đủ đồ" trên nền `herb`, chữ trắng (5.3:1).
- Còn thiếu: "Thiếu: hành lá, cà chua" trên nền `chili-soft`, chữ `chili-deep`. Nên chỉ hiện khi thiếu 1–2 thứ; thiếu nhiều hơn thì đừng gợi ý món đó.
- Chữ 12/16 600, bo `radius-sm`. Truyền `missing` là mảng tên nguyên liệu, viết thường, đúng tiếng Việt có dấu.
