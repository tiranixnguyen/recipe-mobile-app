# Icon

Bộ icon nét tạm thời (24px, nét 2px, bo tròn) theo tinh thần Material Symbols Rounded; trong Flutter dùng `Icons.*_rounded` tương ứng.

- Tên có sẵn: search, clock, person, heart, home, bowl, list, plus, check, compass, fridge, calendar, bookmark, shuffle, back, sliders, timer, minus, close, smile, meh, frown, bell, trash, chevron, alert, info, shield, mail, image.
- Màn hệ thống: bell (thông báo), chevron (cuối dòng cài đặt), alert (lỗi), info (giới thiệu), shield (chính sách), mail (góp ý), image (đính kèm ảnh), trash (xoá dữ liệu); sun, moon, device cho lựa chọn giao diện Sáng / Tối / Theo hệ thống.
- Đánh giá món sau khi nấu: smile (Ngon), meh (Tạm), frown (Chê). close cho nút thoát chế độ nấu.
- Tab: compass (Khám phá), fridge (Tủ đồ), calendar (Thực đơn), bookmark (Đã lưu). Lưu món dùng bookmark; shuffle cho "Đổi món"; sliders mở cài đặt dụng cụ và chế độ ăn.
- Màu theo chữ xung quanh (`currentColor`): `ink`, `ink-muted`, hoặc `chili` khi đang chọn.
