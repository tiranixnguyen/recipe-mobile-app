# BottomNav

Thanh điều hướng dưới cùng với bốn tab: Khám phá, Tủ đồ, Thực đơn, Đã lưu.

- Icon: compass, fridge, calendar, bookmark. Tìm kiếm và Đi chợ không phải tab: Tìm kiếm mở từ ô tìm ở Khám phá, Đi chợ mở từ Thực đơn.
- Tab đang mở: icon và nhãn màu `chili`, icon nằm trong viên `chili-soft`. Tab khác: `ink-muted`.
- Mỗi tab cao tối thiểu 56px. Truyền `active` (id tab: `home`, `pantry`, `plan`, `saved`) và `onChange`; `items` để thay danh sách tab.
