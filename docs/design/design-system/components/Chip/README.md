# Chip

Chip lọc bật/tắt: thời gian, dụng cụ, bữa, chế độ ăn, nguyên liệu trong Tủ đồ.

- Chưa chọn: nền `surface-raised`, viền `outline`. Đã chọn: nền `chili-soft`, chữ và viền `chili-deep`, icon đổi thành dấu tích.
- Bo `radius-pill`, cao 36px; xếp hàng ngang cuộn được (lọc) hoặc xuống dòng (Tủ đồ), cách nhau `space-2`.
- Nhãn ngắn, cụ thể: "Dưới 15 phút", "Nồi cơm điện", "Chay", "Bữa tối". Người dùng truyền `selected` và `onClick`.
