# EmptyState

Trạng thái trống khi danh sách chưa có gì: chưa lưu món, tìm không ra, tủ đồ chưa có gì, thực đơn trống.

- Hình tròn `chili-soft` với icon, tiêu đề 20/600, một câu giải thích `ink-muted`, và tối đa một nút `secondary`.
- Câu chữ chỉ cách thoát ra, không đổ lỗi: "Thử bỏ bớt bộ lọc" thay vì "Không có kết quả".
